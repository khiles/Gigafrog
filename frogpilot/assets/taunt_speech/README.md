# Spoken taunt lines

One wav per Sissy Mode taunt, named by a hash of its two lines of text. Generated by
`frogpilot/tools/make_taunt_speech.py`, which reads the pool from `SISSY_TAUNTS` in
`selfdrive/selfdrived/events.py` so the audio can never drift from what is displayed.

These are committed on purpose: they ship with the fork and reach the device on its next
update, so nothing has to be copied by hand. `soundd` hashes the alert text it is about to
show and plays the matching file; a line with no file is simply silent.

To (re)generate after editing a line, on a machine with a speech synthesiser:

    python3 frogpilot/tools/make_taunt_speech.py          # add --force to redo existing ones
    python3 frogpilot/tools/make_taunt_speech.py --list   # show lines, hashes and voices

Files must be mono, 16-bit, 48kHz — `soundd` refuses anything else. The generator enforces it.

`/data/media/taunt_speech/` on the device takes priority over this directory, so a line can be
dropped straight onto the car without a commit.
